## 三、重试机制全路径推演

1. 打开瞬间缺钥（open_or_create 既有文件分支，:619-625）→ key=nullptr + DEGRADED → 本轮块明文（is_new_target=true → retry_key_probed=true，本轮不再重探——open 已探过一次）；
2. 下一轮 drain：ensure 早退（同 fd）→ is_new_target=false → 守卫通过（enc_capable && encrypt_enable && !key && provider）→ 重探一次；失败 → DEGRADED（每轮至多一次）；成功 → `target.key` 锁定，本轮全部后续块恢复密文；
3. 稳态：key 非空 → 条件恒假 → 零 JNI 开销；
4. 边界：mid-drain 轮换（is_new_target=true）→ 重探跳过（新文件 open 已探）；split 耗尽（fd=-2）→ fd<0 分支先 continue，重探不可达；跨天 → close_current 置空后新开，同 1；
5. 并发面：全路径单 Flusher 线程，`target.key` 单写单读。
